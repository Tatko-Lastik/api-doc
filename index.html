Tatko Lastik — Partner API

Harici sistemlerin ERP ile entegre olmasını sağlayan B2B API. JWT Bearer kimlik doğrulaması kullanır; tüm korumalı endpoint'lere istek atmadan önce token alınmalıdır.

UAT Base URL https://t-uat.tatko1927.com
API Sürümü v1.0
Auth Yöntemi JWT Bearer Token
Format JSON (UTF-8)
🔐
Kimlik Doğrulama
Client credentials akışı — tüm korumalı endpoint'lerden önce çalıştırılmalıdır.
POST /auth/token 🔓 Açık Endpoint

Client kimlik bilgileriyle JWT erişim tokeni ve yenileme tokeni alır. Dönen accessToken tüm korumalı endpoint'lerde Authorization: Bearer <token> başlığı olarak kullanılır.

İstek Gövdesi
AlanTipZorunluAçıklama
clientId string Zorunlu Tatko tarafından sağlanan istemci kimliği
clientSecret string Zorunlu Tatko tarafından sağlanan istemci gizli anahtarı
İstek Örneği
POST https://t-uat.tatko1927.com/auth/token
Content-Type: application/json

{
  "clientId": "partner-xyz",
  "clientSecret": "s3cr3t-key"
}
Başarılı Yanıt — 200 OK
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "tokenType": "Bearer",
  "expiresIn": 3600  // saniye cinsinden (örn: 1 saat)
}
HTTP Durum Kodları
200 Token başarıyla alındı
401 Geçersiz client bilgileri veya pasif hesap
500 Sunucu hatası
POST /auth/refresh 🔓 Açık Endpoint

Süresi dolmaya yakın access token'ı yeniler. Refresh token rotasyonu uygulanır: eski refresh token geçersiz kılınır ve yeni token çifti döner.

💡 Access token süresi dolduğunda kullanıcıyı tekrar giriş yaptırmak yerine bu endpoint ile sessizce yeni token alınabilir. Refresh token kullanıldıktan sonra bir daha kullanılamaz; dönen yeni refreshToken saklanmalıdır.
İstek Gövdesi
AlanTipZorunluAçıklama
refreshToken string (GUID) Zorunlu /auth/token'dan dönen refreshToken değeri
İstek Örneği
POST https://t-uat.tatko1927.com/auth/refresh
Content-Type: application/json

{
  "refreshToken": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
}
Başarılı Yanıt — 200 OK
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refreshToken": "7cb46a31-9911-4e22-a401-5f9d43c66bda",
  "tokenType": "Bearer",
  "expiresIn": 3600
}
HTTP Durum Kodları
200 Token başarıyla yenilendi
401 Geçersiz, süresi dolmuş veya iptal edilmiş token
🔑 Tüm aşağıdaki endpoint'ler için: her istekte HTTP header'ına Authorization: Bearer <accessToken> eklenmelidir. Header eksikse 401 Unauthorized döner.

İl Listesi
Adres kaydında kullanılacak geçerli il kodları ve isimleri
GET /locations/cities 🔒 Bearer Token Gerekli

ERP sistemindeki geçerli il listesini döner. Plaka kodu 01–81 arası, yalnızca sayısal, 2 haneli kodlar gelir.

İstek Örneği
GET https://t-uat.tatko1927.com/locations/cities
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Başarılı Yanıt — 200 OK
{
  "success": true,
  "data": [
    { "ilKodu": "01", "ilAdi": "ADANA" },
    { "ilKodu": "06", "ilAdi": "ANKARA" },
    { "ilKodu": "34", "ilAdi": "İSTANBUL" },
    // ... toplamda 81 il
  ]
}
Yanıt Alanları
AlanTipAçıklama
ilKodustring2 haneli plaka kodu (ör: "34")
ilAdistringİl adı büyük harfle (ör: "İSTANBUL")
📍
İlçe Listesi
İl koduna göre filtrelenebilen ilçe listesi
GET /locations/districts?ilKodu={ilKodu} 🔒 Bearer Token Gerekli

İlçe listesini döner. ilKodu parametresi verilirse yalnızca o ile ait ilçeler gelir; verilmezse tüm ilçeler listelenir.

Query Parametreleri
ParametreTipZorunluAçıklama
ilKodu string Opsiyonel 2 haneli il kodu (ör: 34). Boş bırakılırsa tüm ilçeler gelir.
İstek Örneği — İstanbul ilçeleri
GET https://t-uat.tatko1927.com/locations/districts?ilKodu=34
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Başarılı Yanıt — 200 OK
{
  "success": true,
  "data": [
    { "ilceKodu": "01", "ilceAdi": "ADALAR",    "ilKodu": "34" },
    { "ilceKodu": "02", "ilceAdi": "ARNAVUTKÖY", "ilKodu": "34" },
    // ...
  ]
}
Yanıt Alanları
AlanTipAçıklama
ilceKodustring2 haneli ilçe kodu
ilceAdistringİlçe adı büyük harfle
ilKodustringBağlı olduğu ilin plaka kodu

İstek Örneği
GET https://t-uat.tatko1927.com/customeraddresses
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Başarılı Yanıt — 200 OK
{
  "success": true,
  "data": [
    {
      "adresNo":   1,
      "cadde":    "Atatürk Caddesi No:12",
      "mahalle": "Merkez Mahallesi",
      "sokak":    "Gül Sokak",
      "semt":     "Bağcılar",
      "postaKodu": "34200",
      "ilce":     "BAĞCILAR",
      "il":       "İSTANBUL"
    }
  ]
}
Yanıt Alanları
AlanTipAçıklama
adresNointegerERP adres numarası — sipariş girerken bu değer kullanılır
caddestring?Cadde / açık adres
mahallestring?Mahalle
sokakstring?Sokak

postaKodustring?Posta kodu

POST /customeraddresses 🔒 Bearer Token Gerekli

Token sahibi firmanın ERP cari hesabına yeni bir teslimat adresi ekler. Adres numarası otomatik belirlenir (mevcut max + 1). Dönen adresNo sonraki sipariş isteklerinde kullanılabilir.

Not: il ve ilce alanları sırasıyla GET /locations/cities ve GET /locations/districts endpointlerinden alınan değerler gönderilmelidir.
İstek Gövdesi
AlanTipZorunluAçıklama
caddestringZorunluCadde / açık adres bilgisi
mahallestringZorunluMahalle adı
sokakstring?OpsiyonelSokak adı
semtstring?OpsiyonelSemt adı

ilcestringZorunluGET /locations/districts'ten alınan ilceAdi değeri

iletisimAdistring?OpsiyonelTeslimat adresindeki yetkili kişi adı
emailstring?OpsiyonelE-posta adresi
İstek Örneği
POST https://t-uat.tatko1927.com/customeraddresses
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Content-Type: application/json

{
  "cadde":        "Sanayi Caddesi No:45",
  "mahalle":     "Hürriyet Mahallesi",
  "sokak":        null,
  "semt":         "Esenyurt",
  "postaKodu":   "34510",
  "ilce":         "ESENYURT",
  "il":           "İSTANBUL",
  "tel":          "05551234567",
  "iletisimAdi": "Ahmet Yılmaz",
  "email":        "ahmet@firma.com"
}
Başarılı Yanıt — 200 OK
{
  "success": true,
  "adresNo": 2  // ERP'ye atanan yeni adres numarası

HTTP Durum Kodları
200 Adres başarıyla eklendi

Stok Listesi
Müşteriye özel depo ve fiyat listesi filtresiyle ERP stok verisi
GET /stock?stokKodu={stokKodu}&ebat={ebat} 🔒 Bearer Token Gerekli

Token sahibi müşteriye tanımlı depolar ve fiyat listesi kullanılarak ERP stok verisi döner. Her satırda KDV dahil güncel fiyat, iskonto ve mevcut stok miktarı bilgisi yer alır. Yanıt konfigürasyona göre değişkendir; yalnızca müşteri için açık kolonlar gelir.

Query Parametreleri
ParametreTipZorunluAçıklama
stokKodu string Opsiyonel Stok kodu filtresi — LIKE %stokKodu% uygulanır
ebat string Opsiyonel Lastik ebatı filtresi — ör: 2055516 (205/55R16 → slash ve R kaldırılarak sayısal format)
İstek Örnekleri
// Tüm stok
GET https://t-uat.tatko1927.com/stock
Authorization: Bearer ...

// Ebata göre filtrele
GET https://t-uat.tatko1927.com/stock?ebat=2055516
Authorization: Bearer ...

// Stok koduna göre filtrele
GET https://t-uat.tatko1927.com/stock?stokKodu=BRI.001
Authorization: Bearer ...
Başarılı Yanıt — 200 OK
{
  "success": true,
  "data": [
    {
      "stokKodu":           "BRI.001.20555R16",
      "desen":              "TURANZA T005",

      "ebat":               "205/55R16",
      "mevsim":             "YAZ",

      "sepetteOzelIskonto":0.05,   // %5 ek iskonto

    },
    {
      "stokKodu":            "BRI.001.20555R16",
      "desen":               "TURANZA T005",
      "markaIsmi":          "BRIDGESTONE",
      "ebat":                "205/55R16",
      "mevsim":              "YAZ",
      "kdvDahilFiyat":      2450.00,

Yanıt Alanları
AlanTipAçıklama

desenstring?Lastik desen adı

Sipariş Girişi
ERP'ye yeni sipariş kaydeder; çok kalemli siparişleri destekler
POST /orders 🔒 Bearer Token Gerekli

Yeni bir sipariş oluşturur ve ERP'ye kaydeder. Başarılı yanıtta ERP evrak numarası döner. Fiyat bilgisi ERP'deki güncel fiyat listesinden otomatik hesaplanır; istekte birim fiyat gönderilmesine gerek yoktur.

İstek Gövdesi
AlanTipZorunluAçıklama
warehouseNo integer Zorunlu ERP depo numarası — stok listesindeki her satırda gelen depo bilgisine göre belirlenir
paymentMethod integer Zorunlu Ödeme yöntemi kodu (Tatko tarafından bildirilir)
deliveryTypeCode integer Zorunlu Teslimat türü kodu (Tatko tarafından bildirilir)
adressNo integer Zorunlu ERP adres numarası — GET /customeraddresses'ten alınan adresNo
orderDetails array Zorunlu Sipariş kalemleri — en az 1 adet olmalıdır
orderDetails[].stockCode string Zorunlu ERP stok kodu — stok listesindeki stokKodu değeri
orderDetails[].quantity decimal Zorunlu Sipariş adedi (tam sayı veya ondalıklı)
orderDetails[].detail string? Opsiyonel Satır bazında not / açıklama
documentDescription string? Opsiyonel Evrak genel açıklaması
cityDistrict string? Opsiyonel Şehir / ilçe bilgisi (serbest metin)
cargoCompany string? Opsiyonel Tercih edilen kargo şirketi adı
İstek Örneği — Tek Kalemli Sipariş
POST https://t-uat.tatko1927.com/orders
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Content-Type: application/json

{
  "warehouseNo":      1,
  "paymentMethod":    1,
  "deliveryTypeCode": 0,
  "adressNo":         1,
  "documentDescription": "Web sitesinden verilen sipariş",
  "cityDistrict":    "İstanbul / Bağcılar",
  "cargoCompany":    "YURTIÇI",
  "orderDetails": [
    {
      "stockCode": "BRI.001.20555R16",
      "quantity":  4,
      "detail":    "Yaz lastiği"
    }
  ]
}
İstek Örneği — Çok Kalemli Sipariş
POST https://t-uat.tatko1927.com/orders
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Content-Type: application/json

{
  "warehouseNo":      1,
  "paymentMethod":    1,
  "deliveryTypeCode": 0,
  "adressNo":         2,
  "orderDetails": [
    { "stockCode": "BRI.001.20555R16", "quantity": 4 },
    { "stockCode": "MIC.002.19565R15", "quantity": 2, "detail": "Kış lastiği" }
  ]
}
Başarılı Yanıt — 200 OK
{
  "success":  true,
  "orderNo":  "WEBSIP-1"  // ERP evrak numarası (seri + sıra)
}
Hata Yanıtı Örnekleri
// 400 — Stok yetersiz
{
  "success":  false,
  "message": "BRI.001.20555R16 için yeterli stok yok. Mevcut: 2, Talep: 4."
}

// 409 — Tekrar sipariş engeli
{
  "success":  false,
  "message": "Aynı sipariş son 30 dakika içinde zaten verilmiş."
}

// 403 — Depo yetkisi yok
{
  "success":  false,
  "message": "Bu depoya sipariş verme yetkiniz yok."
}
HTTP Durum Kodları
200 Sipariş ERP'ye başarıyla kaydedildi
400 Doğrulama hatası (stok, adres, limit vb.)
401 Geçersiz token
403 Yetki hatası (sipariş izni veya depo yetkisi yok)
409 Son 30 dakika içinde aynı sipariş gönderilmiş
500 ERP kayıt hatası
